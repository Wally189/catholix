# Catholic Bristol — digital porch prototype

A colourful, offline-first public front door for people in Bristol who have questions about God, life and the Catholic Church but may have no church vocabulary or confidence.

## Product principles

- visitor language before institutional language
- questions before programmes
- human reassurance before procedure
- local character without invented local claims
- one honest next step per page
- accessible, responsive and usable offline after first load
- no personal-data collection in the prototype

## Run locally

Serve the directory over HTTP so the service worker can operate, for example:

```bash
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Important status

This is a prototype, not an official diocesan or parish service. Real contacts, testimonies, safeguarding routes, crisis signposting, event feeds and doctrinal content require authorised review before launch.
